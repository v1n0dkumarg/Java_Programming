# Java Programming

A comprehensive collection of Java programs covering Core Java concepts from beginner to advanced level. This repository serves as a learning reference and practice guide for understanding Java fundamentals, Object-Oriented Programming (OOP), Collections, Exception Handling, Multithreading, Functional Programming, and Stream API.

## 🚀 How to Run

### Compile

```bash
javac FileName.java
```

### Execute

```bash
java FileName
```

Example:

```bash
javac 54.Lambda_Expression.java
java Lambda_Expression
```
